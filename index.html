Rico App Uninstaller

A native macOS utility that builds precise, local uninstall manifests from installation activity initiated by the user.

What Rico does

Rico helps users understand and remove the files created when they install an application. The user explicitly starts a recording session, installs the software, then stops the session. Rico creates a local manifest that can later be reviewed and used to move eligible associated items to the Trash.

  1. The user starts an installation recording.
  2. The application and any official installer run normally.
  3. Rico attributes relevant filesystem activity to that installation.
  4. On uninstall, Rico reports what was removed and what macOS kept or protected.

Why Endpoint Security is requested

Filesystem snapshots and FSEvents can report that a path changed, but they do not reliably identify which process caused the change. Unrelated macOS background activity can therefore be mistaken for part of an installation.

Rico intends to use Apple's Endpoint Security framework in notification-only mode to associate filesystem operations with the responsible process and its descendants. This attribution is needed to reduce false positives and prevent unrelated user or system data from entering an uninstall plan.

  • No authorization, denial, blocking, suspension, or modification of system events.
  • Only process-lifecycle and filesystem notification events needed for installation provenance.
  • Monitoring is active only during a recording session explicitly started by the user.

Privacy

  • Rico does not read or collect file contents.
  • Rico does not collect keystrokes, credentials, network traffic, or personal communications.
  • Event metadata and uninstall manifests remain locally on the user's Mac.
  • No Endpoint Security data is uploaded, sold, or shared.
